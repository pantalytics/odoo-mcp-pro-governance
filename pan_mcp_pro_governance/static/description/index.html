MCP Pro

AI Governance for Odoo

Give every AI agent its own identity. Log every action to an append-only trail. Keep your auditor happy when Claude, ChatGPT or your own bot starts reading and writing your ERP.

Why

Standard Odoo was designed for humans clicking through forms. When an AI agent can fire 5,000 actions per hour against the same user account, the gaps show — no first-class agent identity, API keys with full user permissions, audit depth that doesn't capture the prompt that drove the decision.

This module fills those gaps with thin, well-bounded primitives — it does not replace Odoo's ACLs, it instruments around them.

What's inside

  • Agent identities — first-class model for every AI agent that touches your data, with owner, provider and lifecycle (draft / active / suspended / revoked).
  • Append-only audit log — every agent action writes a row that cannot be edited or deleted, linked to the agent identity, acting user, model, record, request id and prompt hash.
  • Append-only API call log — one row per inbound MCP / API call (method, path, tool, status, duration), joined to the audit log via request id.
  • Security groups — User (read) and Manager (admin), ready for you to assign.

Agent Identities

Register every AI agent that talks to your Odoo. Owner, provider, lifecycle state, last-seen.

Audit Log

Append-only by design. Manager cannot edit or delete — AccessError is raised on attempts. One row per agent action, linked to the identity that did it, the user it acted as, and the request id.

API Call Log

One row per inbound MCP/API call. Method, path, tool, HTTP status, duration. Joined to the audit log via request id so you can trace a single AI prompt all the way down to the records it changed.

Companion to the MCP server

The MCP server itself — the bridge that lets Claude, ChatGPT, Cursor, Gemini and other MCP-compatible AI tools talk to your Odoo — runs outside Odoo. This addon is the oversight surface for that traffic. It works whether you self-host the server or run a hosted equivalent.

No data leaves your Odoo database. No call-home. No telemetry. Open source (LGPL-3) — audit every line.
